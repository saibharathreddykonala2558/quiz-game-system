The Project

Built to understand the language, not just the syntax.

This project began as a hands-on study of C++ fundamentals. It reads questions from an external text file, accepts user answers, calculates a score, and writes the result to a leaderboard.

The source code is public on GitHub. The browser quiz on this page is a separate JavaScript edition created to present the same questions in a more visual form.

Features

Quietly capable, by design.

Question Bank

Questions are loaded from an external text file, making the quiz easy to expand.

Instant Feedback

Each answer is checked immediately, and the score updates as you play.

Saved Results

Final scores are written to a leaderboard file for later review.

Clean Build

Compiled with g++ using the C++17 standard and tested on Windows.
